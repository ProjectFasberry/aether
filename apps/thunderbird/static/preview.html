Quick start

curl-friendly, no auth for public reads
curl -s "/health"
curl -s "/openapi/json" | jq '.info'
curl -s "/yggdrasil"
  • Public reads are rate-limited per IP; authenticated mutations use the session cookie.
  • Launcher and scripts use Authorization: Bearer <key>.
  • Responses use { data }; errors use { error }.
  • Every response carries x-request-id for log correlation.

Authentication

web session · launcher bearer · CAP/PoW

Accounts & sessions

Password login, registration, QR login and session invalidation.

—

Auth model

Cookie sessions for the web, bearer keys for the launcher and internal clients.

  • /privated/* requires an authenticated user or API key.
  • CAP PoW protects login/registration; tokens are single-use.
  • Session lifetime is sliding, with an absolute maximum age.

Yggdrasil

Auth server

Metadata, authenticate, refresh, validate and invalidate.

Signed textures

Profiles carry our own RSA-signed textures property.

  • skinDomains is environment-driven.

  • Fallback skin is always available when the cache is cold.

Server data

player, lands, rating, events, skins

Game server API

Public and authenticated data read from the Minecraft backend.

—

Data ownership

The API reads the game databases; the panel writes through explicit routes.

  • Lands, players, ratings and events are read-heavy public surfaces.
  • Skins come from SkinsRestorer plus a local MinIO cache.
  • Heavy lists are cached and paginated.

Admin API

Users, roles, options, history, store and economy management.

—

Access

Every private route checks a permission from the permissions tree.

  • Use the panel UI or send a bearer API key.
  • Missing permissions return a stable error code.
  • Admin changes are written to the activity log.

Helpful details

what to expect from the API

Response envelope

  • Success: { "data": ... }
  • Error: { "error": "CODE" }
  • Validation failures use 422 and a stable validation payload.

Debugging

  • Send x-request-id or read it from the response.
  • Use /openapi/json to generate a client.
  • Check /health before blaming a route.
The API is a single Elysia service. Public routes are rate-limited per IP; the private group and launcher require credentials.
