# Fasberry Monorepo

[![License](https://img.shields.io/github/license/ProjectFasberry/fasberry?style=for-the-badge)](./LICENSE)

Unified monorepo containing all applications and shared packages for the Fasberry ecosystem. Built with **Bun** for fast, unified dependency management and task execution.

---

## 1. Overview
Fasberry is a full-stack minecraft project with:

| Component | Type | Purpose |
|-----------|------|---------|
| `frontend-app` | React Frontend | Main frontend app |
| `frontend-landing` | React Frontend | Public landing page deployed on Vercel |
| `api-main` | Elysia API | Core REST API |
| `api-panel` | Elysia API | Admin REST API |
| `ui` | Library | Shared React components (Radix UI + Tailwind) |
| `shared` | Library | Shared types, utilities, and constants |
