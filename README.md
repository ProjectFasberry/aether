## Fasberry API Monorepo

Welcome to the Fasberry API Monorepo, the server-side codebase for the Fasberry game platform.

This repository contains:
- Thunderbird - [public and game API](https://api.fasberry.fun)
- Glaux - panel API and Telegram bot service
- Workers - database type generation
- Shared packages - core services, schemas and Drizzle migrations
